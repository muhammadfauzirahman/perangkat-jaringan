# Setup Project Backend

## Tech Stack

- Bun
- ElysiaJS
- Drizzle ORM
- MySQL

## Tasks

1. Init project Bun di root folder.
2. Install dependencies (ElysiaJS, Drizzle, MySQL driver).
3. Setup konfigurasi Drizzle dan koneksi ke MySQL.
4. Buat struktur folder dasar (contoh: `src/db`, `src/routes`).
